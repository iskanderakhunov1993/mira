# Правила дизайна

1. Используй Tailwind CSS для цветовой палитры и классов.

2. Избегай типичного для ИИ стиля интерфейса: случайных градиентов, чрезмерного свечения и лишних декоративных элементов.

3. Создавай компоненты для всех повторяющихся и базовых элементов интерфейса: кнопок, инпутов, чекбоксов и остальных элементов. Также создавай составные компоненты, например хедер и футер, если они переиспользуются несколько раз на разных страницах.

4. Подписи секций и короткие eyebrow-labels пиши обычным регистром, без uppercase, увеличенного `letter-spacing` и искусственного изменения интерлиньяжа.
