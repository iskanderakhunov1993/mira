# UX/UI Product Review

## Context

Read `docs/product/PRODUCT_PRINCIPLES.md`, `FEATURES.md`, and the relevant flow in `USER_FLOWS.md`. Inspect the actual responsive implementation.

## Workflow

1. Define the screen's single primary job.
2. Apply the five-second test.
3. Rank content by primary state, action, context, and detail.
4. Remove duplicate actions and nested-card noise.
5. Check Russian copy, tap targets, contrast, focus, and screen-reader names.
6. Verify narrow mobile layouts before desktop polish.
7. Check component, spacing, typography, color, and interaction consistency.

## Output

- UX/UI score out of 10.
- What is immediately clear.
- Cognitive-load and hierarchy issues.
- Accessibility issues.
- Exact component-level changes.
- Before/after information hierarchy.
- Mobile acceptance criteria.
