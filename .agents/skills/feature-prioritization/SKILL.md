# Feature Prioritization

## Context

Read `docs/product/PRODUCT_OVERVIEW.md`, `PRODUCT_PRINCIPLES.md`, `FEATURES.md`, `ROADMAP.md`, `METRICS.md`, and `DECISIONS.md`.

## Workflow

1. Normalize each item into user problem, segment, outcome, effort, and risk.
2. Remove prerequisites and mandatory P0 work from discretionary scoring.
3. Use RICE when reach and confidence estimates exist.
4. Use Impact/Effort when estimates are directional.
5. Use Kano for delight versus expected basics.
6. Place decisions into Now, Next, Later, or Not Planned.
7. Give one explicit action per item.

## Required recommendation labels

- Keep.
- Simplify.
- Postpone.
- Remove.
- Validate with experiment.

Never present a score without a recommendation and rationale.
