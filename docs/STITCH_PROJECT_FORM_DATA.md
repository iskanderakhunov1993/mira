## Additional Instructions

```text
Create a mobile-first web/PWA concept for Mira based on the attached DESIGN.md and the current MVP scope.

Product: Mira is a private women's cycle and wellbeing diary. It helps a user understand today's cycle context, log important health facts, notice cautious patterns, and prepare a doctor-ready report. It is not a diagnostic app, not a fertility promise, not an emergency triage tool, and not a diet-policing product.

Current MVP screens and flows:
1. Today is the default screen. It should show the user's name, current cycle day/phase, a week strip, a month calendar entry, cycle history, cycle dynamics, and quick actions.
2. Today quick actions: Period opens a beautiful month calendar for marking period days; Symptoms opens tracking; Sex opens a private sex/symptoms bottom sheet.
3. Today lifestyle area: Water shows only the label "Вода" and the current liter value, no percent goal and no glass count. Calories and weight are two equal 50/50 cards: left card "Калории" with a numeric input and save; right card "Вес кг" with a numeric input and save. No food-context chips such as usual, little food, sweets, or heavy food.
4. Track is the source for manual medical entries: period, symptoms, pain, mood, sex, tests, and notes.
5. Analysis shows cautious patterns, sample size, reliability, and cycle dynamics. Avoid diagnosis and overconfident causation.
6. Report is the main outcome: doctor-ready facts with explicit privacy controls before export. Sex and personal notes are off by default.
7. Profile manages privacy, cycle settings, export, and storage.

Visual direction:
Use premium dark iOS health utility style. Warm near-black background, dark espresso cards, electric lime for primary actions/safe active state, vivid pink only for cycle/period/pain signals, muted taupe labels, off-white text. Dense but calm. Avoid landing page style, decorative blobs, gradients, mascots, stock photos, beige spa style, and purple wellness gradients.

Interaction rules:
- Mobile first.
- Bottom navigation stays stable.
- Buttons and inputs must be thumb-friendly.
- Cards should be real content containers, not nested cards.
- Health copy must be short, calm, and non-judgmental.
- Do not show medical diagnosis. Use cautious language: may, could, first signs, based on N entries.
- For medical escalation use: consider discussing this with a qualified clinician.

Generate UI that matches the current Mira MVP rather than a broad wellness app.
```
