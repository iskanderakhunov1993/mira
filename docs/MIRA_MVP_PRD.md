# Mira MVP PRD

## Цель

Первый MVP Mira помогает пользователю быстро понять состояние цикла сегодня, внести важные отметки, увидеть осторожную динамику и подготовить приватный отчёт врачу в web/PWA.

## Пользователь

Пользователь ведёт цикл и симптомы, хочет видеть понятную картину без медицинских диагнозов, быстро сохранять данные с телефона и при необходимости показать врачу структурированные факты.

## North Star

Пользователь за 5 секунд понимает, что происходит сегодня, и за 1-2 минуты может сохранить ключевые данные дня.

## P0 Scope

- Web/PWA работает на мобильном и desktop viewport.
- `/today` показывает имя пользователя, текущий цикл, календарь, историю циклов и динамику.
- Быстрые действия Today:
  - `Месячные` открывает календарь отметки месячных.
  - `Симптомы` ведёт в `/track`.
  - `Секс` открывает модалку симптомов в категории секса.
- Lifestyle на Today сохраняет воду, калории и текущий вес в дневной лог дня.
- Today lifestyle UI:
  - вода показывает заголовок `Вода` и значение в литрах без процента цели и количества стаканов;
  - калории и вес расположены двумя равными карточками 50/50;
  - карточка калорий содержит только ввод калорий и сохранение;
  - карточка веса содержит `Вес кг`, ввод веса и сохранение;
  - food-context варианты вроде `обычно`, `мало еды`, `сладкое`, `тяжёлая еда` не входят в Today MVP.
- `/track` сохраняет симптомы, настроение, сон, секс, тесты и заметки.
- `/analysis` показывает осторожные выводы, динамику и CTA к отчёту.
- `/report` показывает приватные чекбоксы перед экспортом.
- Секс и личные заметки выключены из отчёта по умолчанию.
- TXT export, print/PDF и вопросы врачу не должны падать.
- `/demo` создаёт демо-пользователя для проверки продукта.

## P1 Scope

- PWA manifest и service worker кэшируют ключевые маршруты.
- Empty states объясняют, что добавить дальше.
- Данные, сохранённые в Today/Track, доступны для Analytics/Report через существующий store/bridge.

## Out Of Scope For First MVP

- Реальные AI-запросы в клиенте.
- Диагнозы, прогноз беременности как факт, рекомендации лекарств.
- Полная медицинская интерпретация анализов.
- Нативное iOS/Android приложение.

## Core User Flow

1. Пользователь открывает `/today`.
2. Видит имя, текущий день цикла, календарь, историю и динамику.
3. Добавляет месячные, симптомы, секс или lifestyle данные.
4. Переходит в `/analysis`, чтобы увидеть осторожные паттерны.
5. Открывает `/report`, выбирает приватные разделы и экспортирует отчёт.
6. Через `/profile` управляет данными, приватностью и настройками.

## Data Behavior

- Cycle, logs, care и user данные остаются в Zustand/local bridge, без третьего хранилища.
- Today lifestyle пишет воду, калории и вес в `DailyLog.selfCare` текущего дня.
- Sex сохраняется как приватный контекст и не включается в отчёт без выбора пользователя.
- Report собирает данные через `mergeStoreIntoReportData`.

## Safety And Privacy

- Mira не ставит диагнозы.
- Эскалация формулируется мягко: "consider discussing this with a qualified clinician" / русский эквивалент.
- Интимные данные и личные заметки исключены из doctor export по умолчанию.
- Экспорт всегда требует видимых privacy controls.

## Acceptance Criteria

- `npm run lint --workspace=@mira/web` проходит.
- `npm run smoke --workspace=@mira/web` проходит при запущенном `http://localhost:4173`.
- `/today`, `/track`, `/analysis`, `/report`, `/profile`, `/demo`, `/offline` возвращают 200.
- Все P0 CTA из этого документа кликабельны и не дают runtime errors.
- Report export controls видны на demo-пользователе.
- Service worker содержит ключевые MVP маршруты.
