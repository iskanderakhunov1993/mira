# Пользовательские сценарии

## 1. Первый запуск

Открыть Mira → понять local-first модель → выбрать цель → добавить известные данные цикла или пропустить → настроить модули → попасть на главную.

**Успех:** пользователь видит полезное состояние без обязательной полной анкеты.

## 2. Ежедневная отметка

Открыть главную → выбрать быстрый показатель или дневник → отметить факт → увидеть сохранённое состояние на той же дате.

**Успех:** полезная запись менее чем за 40 секунд.

## 3. Начало месячных

Открыть главную или календарь → отметить кровотечение → подтвердить дату и контекст → пересчитать прогноз.

**Критично:** редактирование существующей отметки не должно случайно удалять её.

## 4. Просмотр прогноза

Открыть главную → увидеть ожидаемый диапазон → понять уровень уверенности → при необходимости открыть календарь.

**Критично:** прогноз визуально отличается от фактических дат.

## 5. Аналитика

Открыть аналитику → увидеть достаточность данных → прочитать один главный вывод → перейти к фактам или истории.

**Критично:** один цикл не выдаётся за закономерность.

## 6. Hormonoscope

Включить карточку → накопить минимум три похожих дня → увидеть три личных наблюдения → дать быструю реакцию.

## 7. Циклоскоп

Включить карточку → прочитать образ дня → выбрать подходящий формат активности → посмотреть маленький знак → оставить реакцию.

## 8. Управление данными

Профиль → управление данными → экспортировать, импортировать или удалить → получить ясное подтверждение результата.
