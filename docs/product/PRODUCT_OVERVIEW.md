# Mira — обзор продукта

## Позиционирование

**Mira помогает понимать себя.** Это приватный PWA-трекер цикла и самочувствия, который превращает ежедневные отметки в понятный контекст и осторожные персональные наблюдения.

## Продуктовая формула

**Метрика → контекст → вывод → действие.**

- Метрика: пользователь отмечает факт или самочувствие.
- Контекст: Mira связывает запись с датой, циклом и личной историей.
- Вывод: продукт показывает объяснимый прогноз или повторяющееся наблюдение.
- Действие: пользователь понимает, что отметить, подготовить или обсудить со специалистом.

## Основная ценность

1. Быстро понять состояние цикла сегодня.
2. Зафиксировать самочувствие без перегруженной формы.
3. Увидеть личные закономерности после накопления данных.
4. Сохранить контроль над чувствительными данными.

## Поверхности продукта

- **Сегодня:** ориентация, прогноз, быстрые действия.
- **Дневник:** фактические записи за выбранный день.
- **Аналитика:** циклы, динамика, повторяемость и достаточность данных.
- **Знания:** короткие материалы по текущему контексту.
- **Отчёт:** подготовка фактов для пользователя или специалиста.
- **Профиль:** настройки, приватность, импорт, экспорт и удаление.

## Отдельные продуктовые слои

- **Основной слой:** цикл, дневник, прогноз, аналитика, отчёт.
- **Научно осторожный слой:** Hormonoscope — наблюдения только по личным похожим дням.
- **Развлекательный слой:** Циклоскоп — атмосферная игровая карточка для настроения без медицинских утверждений.

## Технологическая модель

- PWA, mobile-first.
- React + TypeScript + Vite.
- Основное хранение — зашифрованное состояние в PostgreSQL через Mira API.
- Telegram Mini App подтверждает личность через проверяемый `initData`; PWA использует связанный аккаунт.
- Health-данные не сохраняются в IndexedDB или localStorage.
- Без сети доступен app shell, но загрузка и сохранение истории требуют подключения.
- Пользователь может экспортировать, импортировать и удалить данные.
